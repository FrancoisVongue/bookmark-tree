## Оговорки

- ⚠️ Отмена возвращает библиотеку к состоянию до твоего действия. Вкладки, открытые после него, остаются, но их узлы встают в конец дерева.
- ⚠️ Отмена не открывает заново вкладки, закрытые удалением: узел возвращается спящим.
- ⚠️ После перезапуска браузера вкладка находит свой узел по адресу (Chrome выдаёт вкладкам новые номера). Два спящих узла с одинаковым адресом могут поменяться вкладками.
- Средний клик по живому узлу закрывает вкладку (узел засыпает); по спящему — открывает его в фоне.

## Синхронизация: что нужно от тебя

1. Создать приватный репозиторий на GitHub (пустой).
2. Создать токен (fine-grained) с доступом к этому репозиторию: Contents — Read and write.
3. В панели: «⋯» → Settings → вписать `владелец/репозиторий` и токен → Save and sync.
4. На втором компьютере — то же самое с тем же репозиторием.
